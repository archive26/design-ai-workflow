# Design AI Workflow

디자인 업무를 위한 개인 AI 워크플로우 실험과 개선 기록.

## 목적

개인 실습을 통해 Claude Code의 Skill과 Subagent 활용법을 익히고,
실제 디자인 업무에 적용하면서 나만의 AI 작업 환경을 지속적으로 발전시킨다.

처음부터 완성된 체계를 만드는 대신,
작게 실험하고 결과를 검토하며 유용한 작업 방식과 기준을 축적한다.

## 관리할 자료

| 구분 | 내용 |
|---|---|
| Skills | 반복 업무의 수행 절차, 디자인 기준, 검토 기준 및 출력 형식 |
| Subagents | 조사·분석·검토 등 역할별 에이전트 설정 |
| Prompts | 재사용 가능한 작업 지시 프롬프트 |
| Guides | 업무 진행 순서와 사용 가이드 |
| Reports | 실제 적용 결과, 한계 및 개선 기록 |

위 항목은 앞으로 관리할 자료의 분류이며, 현재 모두 구축된 상태를 의미하지 않는다.

## 첫 실습 방향

기존 광고 이미지에서 받은 피드백을 앞으로 활용할 기획·제작·검토 기준으로 정리하고,
Claude Code의 Skill과 Subagent를 통해 새로운 광고 소재의 제작 시작부터 적용한다.

- Skill: 반복 사용할 작업 절차와 판단 기준을 정리한다.
- Subagent: 정해진 역할과 기준에 따라 조사·분석·검토를 수행한다.
- 디자이너: 업무 목적과 방향을 설정하고, 결과의 근거를 검토해 최종 판단한다.

## 실습 흐름

1. 업무 목적과 기존 피드백 정리
2. Skill·Subagent 개념 및 활용 사례 조사
3. 필요한 개인 Skill·Subagent 구축
4. 실제 디자인 기획·제작·검토에 적용
5. 적용 결과와 한계 확인
6. 지침 보완 및 결과 보고서 작성

## 정리 원칙

- 여러 프로젝트에서 재사용할 공통 지침과 프로젝트별 적용 기록을 구분한다.
- 계획, 실험 중인 내용, 실제로 검증한 내용을 구분한다.
- 실습 과정에서 적용 결과, 한계, 다음에 개선할 점을 기록한다.
- 필요한 최소 구성부터 시작하고 실제 사용 결과에 따라 확장한다.
- 회사 업무 자료는 개인 저장소에 보관 가능한 범위인지 확인한 뒤 포함한다.
- 비밀번호, API 키, 토큰 등 인증 정보는 저장하지 않는다.
