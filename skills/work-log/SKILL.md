# 작업 기록 (work-log)

그날 실제로 진행한 일을 피그마에 **짧은 메모**로 남기는 스킬이다.
목적: 매일 같은 형식을 반복해서 기록 시간을 줄이고, 나중에 실습 결과 보고서의 근거로 쓴다.

## 결과물 형식 (고정)

```
MM/DD 작업 기록                ← 제목 (Noto Sans KR Black 150)
• 한 일 1                      ← 짧은 목록 3~6개 (Regular 80, 단어 단위 줄바꿈)
• 한 일 2
• ...
────────────────────────────
하단 메모 1~2줄                ← 진행 범위 요약 (Medium 64, 회색)
```

- 프레임 이름은 제목과 같게 한다: `MM/DD 작업 기록`
- 폭 6600 (기존 메모 프레임과 같음). 높이는 내용에 맞춘다.
- 흰 배경. 상태 배지, 리뷰 입력란, 다음 작업 목록, 체크리스트는 **넣지 않는다.**

## 기록 원칙 (2026-11-24 사용자 피드백에서 정함)

1. **실제로 진행한 일만 쓴다.** 계획, 평가, 새로운 설명을 덧붙이지 않는다.
2. **사용자가 준 문구가 있으면 그대로 쓴다.** 고쳐 쓰거나 늘리지 않는다.
3. **완료 여부를 추측하지 않는다.** 다른 도구나 사람에게 맡긴 일은 "~에 요청함"처럼 실제로 한 행동만 쓴다.
   - 예: "크롬의 Claude 확장 프로그램에 GitHub 저장소 생성 작업을 요청함" (생성 완료라고 쓰지 않음)
4. **짧게 쓴다.** 항목 하나는 한두 문장으로 쓰고, 항목은 3~6개로 맞춘다.
5. 첫 시도에서 만든 상세한 버전(카드 7개, 상태 칩, 리뷰 칸)은 너무 길다는 피드백을 받았다. 상세 버전은 사용자가 따로 요청할 때만 만든다.

## 작업 순서 (호출 수를 최소로)

### 1. 입력 받기
- **날짜**: 따로 말이 없으면 오늘 날짜를 쓴다.
- **한 일 목록**
  - 사용자가 목록을 주면 → 바로 3단계로 간다.
  - 목록이 없으면 → 이번 대화에서 실제로 한 작업만으로 초안을 만들어 **채팅에 먼저 보여주고 확인을 받는다.** 대화에 없는 내용은 쓰지 않는다.
- **하단 메모**: 사용자가 주면 그대로 쓴다. 없으면 "오늘은 ~까지 진행." 한 줄로 초안을 만들어 목록과 함께 확인받는다.

### 2. 기록 위치
- **기본 위치는 없다.** 사용자가 이번 요청에서 피그마 링크를 주지 않았으면 먼저 묻는다: "기록할 피그마 페이지 링크를 알려주세요."
  - 같은 대화에서 이미 받은 링크가 있으면 다시 묻지 않고 그 링크를 쓴다.
  - 프로젝트의 CLAUDE.md나 HANDOFF.md에 기록 위치가 적혀 있으면, 그 위치를 쓸지 한 줄로 확인한다.
- 링크에서 fileKey와 페이지 id를 꺼낸다 (`node-id=159-530` → `159:530`).
  - 링크의 노드가 페이지가 아니라 프레임이면, `get_metadata`로 그 노드가 속한 페이지 id를 찾는다.
- 배치 규칙 (`scripts/figma-work-log.js`가 자동으로 계산):
  - 이미 `M/D 작업 기록` 형식의 프레임이 있으면 → 가장 아래 기록 프레임 밑에 200 띄워서 둔다.
  - 없으면 → 페이지 맨 오른쪽 노드 오른쪽에 400 띄워서 y 0에 둔다.
  - 다른 노드와 겹치면 만들지 않고 겹치는 노드 이름을 돌려준다 → 사용자에게 위치를 묻는다.

### 3. 피그마에 쓰기 (Figma MCP)
1. `create_session` (fileKey, "daily work log frame")
2. `figma-use` 스킬을 로드한 뒤 `use_figma`로 `scripts/figma-work-log.js`를 실행한다. 맨 위 `INPUT` 값(날짜, 목록, 메모, 페이지 id)만 바꾼다.
3. 반환된 frameId로 `get_screenshot`을 한 번 찍어 사용자에게 보여준다.
4. 링크를 함께 준다: `https://www.figma.com/design/<fileKey>/?node-id=<frameId에서 :를 -로>`

### 4. 수정 요청이 오면
- 기존 기록 프레임을 **직접 수정한다** (복제하지 않음). 수정 전에 `get_metadata`로 현재 상태를 다시 읽는다. 사용자가 위치를 옮겼을 수 있으므로 위치는 바꾸지 않는다.
- 다른 프레임, 메모, 업무 보드는 건드리지 않는다.

## 지켜야 할 것
- 오토레이아웃을 쓰지 않는다. 일반 프레임, 텍스트, 도형만 쓴다.
- 텍스트는 편집 가능한 레이어로 만든다 (이미지로 만들지 않음).
- 폰트는 Noto Sans KR (Regular / Medium / Black). Inter로 바꾸지 않는다.
- 한글 줄바꿈은 단어 단위로 끊는다 (스크립트가 U+2028로 처리). 문구를 고치면 다시 계산한다.
- 기존 메모와 프레임은 수정하거나 옮기지 않는다.
- 사용자가 "피그마는 수정하지 마"라고 하면 쓰기 작업을 하지 않는다.
- GitHub 등 외부 서비스에는 올리지 않는다 (사용자가 따로 요청할 때만).

## 다른 프로젝트·다른 사람에게 줄 때
- `work-log` 폴더 전체(SKILL.md + scripts/)를 `~/.claude/skills/` 또는 `프로젝트/.claude/skills/`에 넣는다.
- 필요한 것: Claude Code에 Figma MCP 연결, 피그마에서 Noto Sans KR 사용 가능.
